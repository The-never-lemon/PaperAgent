# 论文精读方法论

这份文档写的是「读一篇论文正文时该注意什么、写评价时该守什么纪律」，供精读链路
的**分段阅读**与**汇总评价**两个阶段按需取用。

它只管方法，不管输出格式——每一段笔记要写成什么形状、报告要有哪些字段，由
`Prompts.py` 里的提示词规定。

每个二级标题就是一个小节，`Prompts.py` 按小节名取用，所以**不要改标题文字**，
改了会在程序启动时直接报错。

## 逐段阅读取舍

一段正文的笔记有 500 字上限，装不下时按这个顺序取舍：

**先保方法与实验数据，后丢背景与相关工作。**

- 遇到对比表格，写成「数据集 + 指标 + 数值」，不要用「效果更好」代替具体数字。
- 遇到公式，保留算子和变量含义，不要只写「作者定义了一个损失函数」。
- 遇到图，保留图号和图注文字即可，不要描述画面。
- 背景、动机、相关工作各留一句概括就够。

## 评价纪律

写评价类字段时，只根据输入材料里确实出现的内容下判断。下面四条是硬禁止：

1. 不得断言论文「没有做消融实验」「没有对比 baseline」——材料没提不等于论文没做，要写成「输入材料未提及」。
2. 不得断言「只在仿真环境中验证」——除非材料明确写了实验只在仿真里做。
3. 不得断言某工作是已有工作的「翻版」「换皮」——除非能指出方法层面的具体相同点。
4. 不得对不确定的事实使用肯定语气，不确定就写「输入材料未提及」或「需要看全文确认」。

可以且应该做的：指出论文自己声称借鉴或对比了哪些工作、方法的假设是否过强、适用
范围是否偏窄；即使结果好，也指出其评估范围的局限。

打分要与证据强度匹配：材料覆盖得越少越要保守。只有标题和摘要时，除非摘要本身给出
了明确依据，不要给高分或低分。
