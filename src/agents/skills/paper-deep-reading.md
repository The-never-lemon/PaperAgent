# 论文精读方法论

这份文档写的是「读一篇论文正文时该注意什么、写评价时该守什么纪律、公式该怎么写」，
供精读链路的分段阅读、汇总评价、摘要降级三个阶段按需取用。

它只管方法，不管输出格式——每一段笔记要写成什么形状、报告要有哪些字段，由
`Prompts.py` 里的提示词规定。个别地方会用括号点一下字段的名字，那只是为了说得
清楚，字段名一律以 `Prompts.py` 为准。

每个二级标题就是一个小节，`Prompts.py` 按小节名取用，所以**不要改标题文字**，
改了会在程序启动时直接报错。

## 逐段阅读取舍

一段笔记上限 500 字，超出部分会在生成之后**从末尾直接截掉**（按字数硬切，你看不到
刀落在哪）。所以最该留的写在最前面：

- 开头概括压到 50 字以内。
- 事实按重要性从高到低排：先写方法与实验数据，再写结论，最后才是背景与相关工作。
- 遇到对比表格，写成「数据集 + 指标 + 数值」，不要用「效果更好」代替数字；表格数值最密，别省。
- 遇到公式，用 $...$ 原样保留算子和变量含义，不要只写「作者定义了一个损失函数」。
- 遇到图，保留图号和图注即可，不要描述画面。
- 背景、动机、相关工作各留一句，排在最后，被截掉也不可惜。

## 公式写法

报告字段里出现公式或数学符号时，排布和内容都按下面的要求来。

**排布**：行内公式用 $...$ 包住，独占一行的大公式用 $$...$$ 包住。不要把 $ 剥掉只留
公式源码，也不要翻译成「损失函数」这样的自然语言描述——报告是给人看的，公式要能
原样排版出来。

**内容**：照抄输入材料里的写法，不要自己改写。

- 符号沿用原文：材料用 $q$ 表示的东西，报告里不要改成 $p$。
- 不要漏算子：期望、梯度、求和范围、停止梯度这类符号都要写全。
- 文字描述的性质要在公式里体现：文字写了「停止梯度」，公式里就要有对应的算子。
- 同一个符号不能一身兼两职：材料把求和变量和自由变量写成同一个字母时，照抄原文并点一句，不要自行改名掩盖。
- 求和、积分的上下限和上下标要逐个核对材料，范围写错比漏写更误导。
- 材料里的公式本身残缺或明显被切断时，如实写「公式不完整」，不要凭记忆补全。
- 写进字段的公式要自带说明：先用一句话点明它是什么（如「总损失」），再写公式，然后一句说它算出来的是什么；公式里新出现的符号逐个说明含义，材料没解释的就跳过，不要猜。

## 评价纪律

写评价类字段时，只根据输入材料里确实出现的内容下判断。四条硬禁止：

1. 不得断言论文「没有做消融实验」「没有对比 baseline」——材料没提不等于论文没做。
2. 不得断言「只在仿真环境中验证」——除非材料明确写了实验只在仿真里做。
3. 不得断言某工作是已有工作的「翻版」「换皮」——除非能指出方法层面的具体相同点。
4. 不得对不确定的事实使用肯定语气，不确定就写「输入材料未提及」或「需要看全文确认」。

「输入材料未提及」是关于材料的话，不是关于论文的话。只在你想下的判断本身是否定性的
（「没做」「只在」「不如」）时才用它兜底；其余情况留空即可——每个字段都填一句，报告
就成了免责声明，反而没信息。

可以且应该做的：指出论文自己声称借鉴或对比了哪些工作、假设是否过强、适用范围是否
偏窄；从实验覆盖面看评估是否充分——跨数据集、不同设置、消融有没有覆盖它自己提出的
每个模块，缺哪块就点哪块，并说清是材料里没看到、不是论文没做；指出计算成本、数据
需求、工程复杂度上的问题；即使结果好，也指出其评估范围的局限。

四个评价维度（relevance 相关性、novelty 新颖性、rigor 严谨性、clarity 清晰度）的分数
和综合总分，都要和证据强度、以及这个维度本来能不能判断挂钩，不要一律给中间偏高的分：

- 材料只有标题和摘要时，严谨性和清晰度判断不了，这两维给 50 分上下，理由写明「仅有摘要，无法判断」。
- 有正文材料时，严谨性把可复现性算进去：代码、模型权重、训练细节（超参、硬件、轮数）、数据获取，缺哪几项分就低在哪，理由写明缺的是哪几项；材料没提就写「输入材料未提及」，不要断言「没开源」。
- 相关性要拿材料里出现的用户研究主题或关注角度来比；没有可比对的主题时同样给中性分并说明，不要因为论文本身有意思就打高分。
- 理由只写「为什么是这个分」，不要写成对论文的再介绍。

## 字段句式模板

字段名和取值范围一律以提示词为准，这里只规定每条内容该怎么写成一句话。

- 研究问题那条写成「针对{什么不足}，提出{什么}」，不要只把标题换个说法。
- 方法类先给一句从输入到输出的整体流程（如 输入 → 骨干 → 核心模块 → 输出），再按「{组件}：{作用}，靠{机制}做到」一个组件一条写，最后一句说清它和现有方法的核心区别；不要画字符画，没有这种流程的方法跳过第一句。
- 数据集那条带上规模和特点，写成「{名称}（{规模}，{特点}）」，材料没提的项跳过。
- 结果类写成「在{数据集或设置}上，{对象}的{指标}是{数值}（{对比对象}是{数值}）」，缺哪项就省哪项，不要用「效果更好」代替没写出来的数值。
- 实验设置按 数据集 → 评价指标 → 骨干或超参 → 训练细节 排，材料没提的直接跳过，不要补。
- 数字照抄材料，不四舍五入、不换单位，带上材料里的单位。
- 总结那条按提示词的字数要求写；走「只有摘要」的降级路径时，开头先写「基于摘要的精读」。
