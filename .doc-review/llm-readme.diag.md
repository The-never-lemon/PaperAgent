# doc/LLM-README.md 诊断

核对范围：`doc/LLM-README.md` 全文（原文 776 行）对照 `src/llm/` 下 6 个文件，另抽查了 `src/services/chat_runtime.py`、`src/services/settings.py`、`src/agents/reading/relevance.py`、`config/model.example.json`、`config/system.yaml`。

## 一句话总评

这篇文档的骨架很好（4 问开场、8 条决策的四段式、逐文件讲解、行号可核对），但它把一条不属于快照的配置字段写成了快照字段，并且在讲 `base.py` 时前后自相矛盾——对一个要照着它读代码的新人来说，这两处会直接把方向带偏。
